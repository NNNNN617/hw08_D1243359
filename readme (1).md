## 三、 作業問題回答

### 問題一：為什麼 `"4"` 要先轉成數字，才能用於本題的分攤計算？
在 Python 中，加上雙引號的 `"4"` 屬於字串型別（`str`），代表文字符號而非數值。在計算每人分攤費用時，我們需要執行除法運算（`應付總額 / 分攤人數`），但 Python 不允許將數字（`float` 或 `int`）直接除以字串，若未先轉型會發生 `TypeError` 型別錯誤，因此必須先使用 `int("4")` 將其轉換為整數 `4` 才能進行數學計算。

### 問題二：如果先扣折價券，再依剩餘餐費計算服務費，第一組的應付總額會變成多少？為什麼和題目規定的結果不同？
* **計算過程**：
  1. 先扣除折價券：$1200 - 100 = 1100$ 元
  2. 再依剩餘餐費計算 10% 服務費：$1100 \times 0.10 = 110$ 元
  3. 應付總額：$1100 + 110 = 1210$ 元
* **結果差異原因**：題目規定服務費必須以**原始餐費（1,200 元）**計算，因此服務費為 120 元、應付總額為 1,220 元；若先扣除 100 元折價券再算服務費，計算服務費的基準（母數）會變小，導致服務費少算了 $100 \times 10\% = 10$ 元，最終總金額也因此從 1,220 元變為 1,210 元。
